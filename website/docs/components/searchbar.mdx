# Searchbar

A text input preconfigured for search — leading search icon, always-clearable, and optional debounced `onChangeText`.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `icon` | `TVajraIconComponent` | | Leading icon. Defaults to a plain 🔍 glyph. |
| `debounceMs` | `number` | `0` | Delay before `onChangeText` fires after typing stops. `0` disables debouncing. |

Also accepts all `Input.Outline` props (`value`, `onChangeText`, `label`, `size`, etc.) except `startElement` and `isClearable`, which Searchbar sets internally.
