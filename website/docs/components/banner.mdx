# Banner

A persistent, full-width, page-level message bar — distinct from `Alert` (inline, rounded, sits within content) and `Toast` (ephemeral, floating).

## Playground

<Playground
  controls={{

  }
/>

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `message` | `string` | | Required. Banner text. |
| `title` | `string` | | Optional heading above the message. |
| `variant` | `'default' \| 'success' \| 'error' \| 'warning' \| 'info'` | `'default'` | Visual style (shares Alert's tone system). |
| `onDismiss` | `() => void` | | When provided, renders a dismiss button. |
| `icon` | `ReactNode` | | Overrides the variant's default icon. Pass `null` for no icon. |
| `dismissIcon` | `TVajraIconComponent` | | Icon shown in the dismiss button. Defaults to a plain ✕ glyph. |
| `action` | `{ label: string; onPress: () => void }` | | Optional inline action (e.g. "Retry", "Update now"). |
