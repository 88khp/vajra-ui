# Divider

A styled `Separator` with two extra affordances: an inset margin and a centered label (e.g. "OR").

## Playground

<Playground
  controls={{
    label: { type: 'text', label: 'Label', default: 'OR' },
  }}
  render={values => (
    <Col gap="s-3" style={{ width: '100%' }}>
      <Text variant="body">Above</Text>
      <Divider label={values.label || undefined} />
      <Text variant="body">Below</Text>
    </Col>
  )}
  code={values => `<Divider${values.label ? ` label="${values.label}"` : ''} />`}
/>

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Direction of the line. `label` and `inset` only apply when horizontal. |
| `thickness` | `number` | | Line thickness in px. |
| `color` | `TVajraColors` | `'border'` | Line color token. |
| `variant` | `'solid' \| 'dashed' \| 'dotted'` | | Line style. |
| `inset` | `TSpacingToken` | | Margin pulled in from both ends of the line. |
| `label` | `string` | | Text centered on the line. |
