# Drawer

A slide-in side panel — same backdrop/dismiss behavior as [Sheet](./sheet), anchored to the left or right edge instead of the bottom.

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `isVisible` | `boolean` | | Required. Controls visibility. |
| `onClose` | `() => void` | | Required. Called on backdrop press, drag-dismiss, or `onRequestClose`. |
| `edge` | `'left' \| 'right'` | `'left'` | Which edge the drawer slides in from. |
| `closeOnBackdropPress` | `boolean` | `true` | Closes when tapping outside the drawer. |
| `animation` | `'fade' \| 'slide' \| 'scale'` | `'slide'` | How the drawer enters/exits. |
| `dismissOnDrag` | `boolean` | `true` | Drag the drawer toward its edge to dismiss it. |
| `width` | `number` | `300` | Width of the drawer panel. |
| `bg` | `TVajraColors` | `'surface'` | Panel background color. |
| `rounded` | `TRoundedToken` | | Corner radius on the panel's open edge. |
| `p` | `TSpacingToken` | `'s-4'` | Panel padding. |
| `backdropColor` | `TVajraColors` | `'overlay'` | Backdrop color. |
