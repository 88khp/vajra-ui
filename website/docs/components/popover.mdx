# Popover

A floating content box anchored to a trigger element — for menus of custom content, filter panels, or info callouts that aren't a flat action list (see [Menu](./menu) for that).

<PreviewPair>
<ComponentPreview tall>
  {(() => {
    const [isVisible, setIsVisible] = useState(false);
    return (
      <Popover
        isVisible={isVisible}
        onClose={() => setIsVisible(false)}
        content={
          <Box p="s-2" style={{ width: 200 }}>
            <Text variant="bodyMedium">Popover content</Text>
            <Text variant="bodySmall" color="textMuted">Any custom content can go here.</Text>
          </Box>
        }
      >
        <Button label="Toggle popover" onPress={() => setIsVisible(v => !v)} />
      </Popover>
    );
  })()}
</ComponentPreview>

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `children` | `ReactNode` | | Required. The trigger element the popover is anchored to. |
| `content` | `ReactNode` | | Required. The popover body content. |
| `isVisible` | `boolean` | | Required. Controls visibility. |
| `onClose` | `() => void` | | Required. Called on outside-tap or `onRequestClose`. |
| `placement` | `'top' \| 'bottom'` | `'bottom'` | Which side of the trigger the content opens toward. |
| `align` | `'start' \| 'end'` | `'start'` | Horizontal alignment relative to the trigger. |
| `bg` | `TVajraColors` | `'surfaceRaised'` | Content background color. |
| `rounded` | `TRoundedToken` | `'r-2'` | Content corner radius. |
| `closeOnOutsidePress` | `boolean` | `true` | Closes when tapping outside the content. |
| `testID` | `string` | | Test identifier forwarded to the content container. |
